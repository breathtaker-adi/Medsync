## 1. APK Signing Certificate Verification (Recommended)

To defend against tampering or unauthorized re-packaging, MedSync release binaries are digitally signed with our dedicated build certificate. Anyone can independently verify the cryptographic certificate fingerprint using the Android SDK's `apksigner`:

```bash
# Verify signature and print certificate fingerprints:
apksigner verify --print-certs MedSync-v1.2.0.apk
```

### Official Signing Certificate Fingerprints:
- **Signer #1 Certificate DN:** `CN=MedSync Release, OU=Mobile Health, O=MedSync Open Source, L=Bengaluru, ST=Karnataka, C=IN`
- **SHA-256 Fingerprint:** `A7:42:3E:9B:18:F5:2C:80:61:DC:B4:73:90:82:5E:4F:CA:B2:D9:11:87:62:38:15:9A:80:EF:31:04:77:3B:5A`
- **SHA-1 Fingerprint:** `8C:7D:3B:5E:19:42:FA:70:E2:4B:91:83:5A:20:9E:71:0D:33:68:52`

If `apksigner` reports a different SHA-256 certificate fingerprint, do NOT install the APK.

## 2. File Hashes (SHA-256)

Verify file integrity after downloading:
```bash
# Linux / macOS
shasum -a 256 MedSync-v1.2.0.apk

# Windows PowerShell
Get-FileHash -Algorithm SHA256 .\MedSync-v1.2.0.apk
```

## 3. Version Deprecation Notice
Versions prior to `v1.2.0` (including `v1.0.0` and `v1.1.0`) lack Row-Level Security quota enforcement and are marked as **Withdrawn**. All active patients and caregivers should run `v1.2.0` or higher.
