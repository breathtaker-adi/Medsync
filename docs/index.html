Next-Gen Medication Adherence & AI Prescription OCR

MedSync is an accessible mobile health (mHealth) ecosystem bridging seniors, caregivers, and licensed physicians to eliminate preventable medication errors and maximize therapy adherence.

View GitHub Repository ↗ Download Latest Android APK 📲

Built for Real Healthcare Impact

  • ✅ Senior Accessibility First: Oversized buttons, WCAG AAA contrast, and Text-to-Speech (TTS) audio directions.
  • ✅ AI Vision OCR Engine: Snap prescriptions to extract drug name, dosage strength, and frequency in seconds.
  • ✅ Fail-Safe Caregiver Watch: Instant push alerts trigger automatically if seniors miss scheduled medications.
  • ✅ Doctor Registry Verification: Dedicated clinician approval portal with official state medical licensing validation.

A Unified Healthcare Triad

Designed specifically to overcome the $300B annual crisis of prescription non-adherence.

👵

Patient & Senior Mode

High-contrast interface, native voice announcements (expo-speech), tactile haptics (expo-haptics), and one-tap dose logging with PDF health report printing.

👨‍👩‍👧

Caregiver Telemetry

Live remote tracking of parents' adherence streaks, safety grace period countdowns, and automated emergency notifications for missed doses.

🩺

Physician Verification

Official medical registry credentialing, pending prescription approval queue, and patient directory to adjust dosage regimens safely.

🤖

AI Prescription Scanner

Edge Functions running multi-modal computer vision to convert paper and handwritten prescription photos into structured medication regimens.

Enterprise System Architecture

MedSync is engineered with an offline-first mobile client powered by Supabase PostgreSQL 15, Deno Edge Computing, and Expo Push Notification infrastructure.

📱 Client Layer

React Native 0.86, Expo Router typed navigation, hardware-backed SecureStore, native Print Spooler.

⚡ Edge Functions

scan-prescription AI OCR processor & check-missed-doses scheduled adherence cron.

🔒 Security & RLS

PostgreSQL Row Level Security isolating patient records, active caregiver links, and doctor clinical scopes.

📡 Notification Cloud

Expo Push Gateway dispatching low-latency alerts to Google FCM (Android) and Apple APNs (iOS).

Security & Compliance Safeguards

Engineered under defense-in-depth principles and core HIPAA / DPDP privacy standards.

🛡️

Row Level Security

Every database table strictly enforces RLS policies. Clients cannot read or tamper with unlinked records.

🔐

Tamper-Proof Triggers

Database-level triggers prevent clients from escalating privileges or self-granting verified doctor badges.

🔑

Hardware Keychain

Authentication sessions and encryption keys are stored inside device hardware keystores via Expo SecureStore.

🧪

67 Automated Tests

Comprehensive test suite continuously validating IDOR protections, RLS integrity, and fail-closed edge functions.
